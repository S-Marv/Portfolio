# Portfolio

A portfolio site developed using Vue.js and the primevue component library. The site is hosted on github pages [here](https://s-marv.github.io/Portfolio/).

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Run Unit Tests with [Vitest](https://vitest.dev/)

```sh
npm run test:unit
```
